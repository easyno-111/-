# 랜덤 아레나 V8.2 검증과 조작

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
node tests/arena-highlights.cjs
ARENA_FULL_MATRIX=1 node tests/arena-course-physics.cjs
node tests/arena-chase.cjs
node tests/arena-browser.cjs
```

기본 코스는 약 30초, 긴 코스는 1분 이내를 목표로 길이를 줄였습니다. 공통 진행 속도를 실제 주행 진척에 맞춰 조절하며 당첨자를 사전에 지정하지 않습니다. ‘빠르게 진행’은 추가 배속입니다.

## 추격 이벤트

- **중간 추격**: 선두가 코스의 약 48%에 도착하면 경기 시간과 일반 물리를 멈춥니다. 카메라가 하위 절반으로 이동한 뒤 불꽃 부스터로 추격시킵니다. 인원이 홀수면 하위 절반을 내림해서 선정합니다.
- **결승 꼴등 부스터**: 첫 골인 전 결승선 근처에서 꼴등 한 명을 비춘 뒤 결승 구간까지 추격시킵니다. 재개 직후 짧은 슬로모션을 적용합니다.
- 이벤트는 각각 한 번만 발생합니다. 두 체크박스를 독립적으로 설정하고 현재 브라우저에 저장합니다. 끄면 공을 앞으로 옮기는 추격 이벤트가 발생하지 않습니다.
- 카메라 이동·점화 동안 모든 공이 정지하고, 발진 중에는 대상 공만 이동합니다. 이동 경로에서는 일반 충돌을 잠시 쉬고, 도착 지점은 벽·장애물·다른 공과 겹치지 않는 곳을 찾습니다.
- 도착 지점은 선두보다 뒤에 두며 이벤트 자체가 골인을 기록하지 않습니다. 재개 후에는 실제 경기로 순위가 바뀔 수 있습니다. 이 기능은 추격 대상의 실제 위치를 바꾸는 게임 규칙입니다.
- 중단하면 이벤트도 중단됩니다. 회전/화면 크기 변경 중에는 이전 화면 좌표로 공이 튀지 않도록 이벤트를 취소하고 경기를 재개합니다.

## 회전 구조

회전판은 네 개의 뼈대와 짧게 끊긴 외곽 지지대, 작은 축으로 구성됩니다. 원판 전체를 채우지 않으며 보이는 뼈대에만 충돌합니다. 외곽의 열린 부분으로 공이 안에 들어왔다가 빠져나갈 수 있습니다. 렌더링·충돌·부스터 도착 검사에서 같은 선분 정보를 사용합니다.

## 자동 검증

- `arena-course-physics.cjs`: 실제 물리 엔진으로 기본/긴 코스의 간격, 뼈대 내부 진입, 회전 충돌, 중심점 탈출, 여러 화면·난수 조건의 골인을 검사합니다. 렌더링에 쓰지 않는 캔버스 표면만 대체합니다.
- `arena-chase.cjs`: 경기 정지, 카메라 상승, 하위 절반 선정, 안전한 도착 지점, 선두를 넘지 않는 합류, 골인 미기록, 옵션·일회성·화면 변경 처리를 검사합니다. 144개 라운드 조건에서 카운트다운과 결과·리플레이 여유를 포함한 시간 예산도 확인합니다.
- `arena-browser.cjs`: PC·모바일 브라우저 조작, 옵션 저장, 중간 이벤트 정지, 결승 추격, 실제 전경 라운드의 1분 이내 완료, 뼈대 렌더링, 기존 결과·명단·팀 기능을 검사합니다.

브라우저 테스트는 임시 HTTP 서버를 시작·종료하고 외부 서비스와 운영 DB에 접근하지 않습니다. `ARENA_ARTIFACTS`를 지정하면 화면 캡처를 저장합니다. GitHub Actions의 `Arena V8 checks`가 동일한 검증을 실행합니다. 시간 검증은 테스트 표본과 정상적인 전경 실행에 대한 회귀 검증이며, 백그라운드 탭·기기 정지 같은 환경까지 보장하는 실시간 제한은 아닙니다. 실제 iPad/Safari 실기기 검증은 별도로 필요합니다.
