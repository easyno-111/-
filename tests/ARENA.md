# 랜덤 아레나 V8 검증

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
node tests/arena-highlights.cjs
node tests/arena-browser.cjs
```

브라우저 검증은 테스트 HTTP 서버를 자동으로 시작·종료합니다. 외부 서비스와 운영 데이터베이스에 접근하지 않습니다. `ARENA_ARTIFACTS` 경로를 지정하면 준비 화면, 모바일 관전, 역전 알림, 시상대 화면을 저장합니다. GitHub Actions의 `Arena V8 checks`가 같은 검증을 실행합니다.

검증 범위: 세 가지 모드, 기존 V7 설정 이전, 코스 선택, 응원 번호·추적, 빠르게 진행·중단, 카운트다운 취소, 같은 물리 스텝의 골인 판정, 시상대와 당첨 제외 기록, 실제 위치 관찰에 따른 선두 교체, 세 코스의 자연 골인, 전체 순서 공개와 건너뛰기, 팀 정원 균등 배분, 모바일 화면 넘침.

역전 감지 단위 검증은 선두 유지 시간·알림 간격·순위 상승·완주자 제외·구조 동작 제외를 다루며, 관찰기가 공의 위치와 속도를 수정하지 않는지도 확인합니다. 코스 완주 검증은 고정된 난수 표본에 대한 회귀 검증으로, 모든 번호의 동일 당첨 확률이나 모든 배치의 완주 시간을 보장하는 통계 검증은 아닙니다.

## 사용 방식

- 번호 뽑기는 실제 물리 골인 순서로 1~10명을 선발합니다. 3명까지는 시상대를 보여줍니다.
- 선두 교체는 같은 공이 0.3초 이상 선두를 유지할 때 알립니다. 1.6초 간격의 순위 비교로 3계단 이상 상승한 공을 강조합니다. 전체 알림 간격은 최소 2초이며, 골인으로 다른 공이 목록에서 빠진 일은 역전으로 세지 않습니다.
- 기본은 순수 물리입니다. 추격 바람과 강화 옵션은 설정에서 명시적으로 선택할 수 있습니다. 막힌 공을 풀어 주는 공통 구조 동작은 모든 옵션에 적용됩니다.
- ‘빠르게 진행’은 물리 계산 속도를 높이며 당첨자를 별도로 정하지 않습니다. 전체 순서는 처음 섞은 순서를 그대로 공개하며 ‘결과 바로 보기’가 가능합니다.
- ‘중단’은 해당 경기의 기록을 저장하지 않습니다. 기존 완료 경기의 당첨 제외 기록은 유지됩니다.
- 실제 iPad/Safari 실기기 검증은 별도로 필요합니다. 자동 브라우저 검증은 Chromium의 PC·모바일 터치 환경을 사용합니다.
