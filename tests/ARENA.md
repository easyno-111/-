# 랜덤 아레나 V8.3 검증과 조작

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
node tests/arena-highlights.cjs
ARENA_FULL_MATRIX=1 node tests/arena-course-physics.cjs
node tests/arena-chase.cjs
node tests/arena-browser.cjs
```

기본 코스는 약 30초, 긴 코스는 1분 이내를 목표로 길이를 줄였습니다. 공통 진행 속도를 실제 주행 진척에 맞춰 조절하며 당첨자를 사전에 지정하지 않습니다. ‘빠르게 진행’은 추가 배속입니다.

## 추격 이벤트

- **중간 추격**: 선두가 코스의 약 48%에 도착하면 경기 시간과 일반 물리를 멈춥니다. 카메라가 하위 절반으로 이동한 뒤 선두와의 격차를 최대 75% 회복합니다. 인원이 홀수면 하위 절반을 내림해서 선정합니다. 선두 뒤의 간격을 확보한 뒤 재개 후 물리 시간 1.6초 동안 실제로 가속합니다.
- **최후의 역전 부스터**: 선두가 결승선 약 420px 앞에 도착하면 꼴등이 선두와의 격차를 최대 90% 회복하고, 물리 시간 1.4초 동안 강하게 가속합니다. 추월할 시간이 있도록 기존보다 일찍 시작하며, 도착 지점은 선두 최소 140px 뒤·결승선 최소 240px 전입니다. 재개 직후 짧은 슬로모션을 적용합니다.
- 이벤트는 각각 한 번만 발생합니다. 두 체크박스를 독립적으로 설정하고 현재 브라우저에 저장합니다. 끄면 해당 이동·가속 모두 발생하지 않습니다.
- 카메라 이동·점화 동안 모든 공이 정지하고, 발진 중에는 대상 공만 이동합니다. 가로 위치는 유지하고 도착 지점은 벽·장애물·다른 공과 겹치지 않는 곳을 뒤쪽으로 찾습니다. 안전한 위치가 없으면 위치를 옮기지 않습니다.
- **실제 역전 가능**: 정지 연출 자체는 선두를 넘거나 골인을 기록하지 않습니다. 경기 재개 후 부스터 가속은 장애물·공 충돌과 결승선 판정을 그대로 적용합니다. 중간 부스터 속도 상한은 610px/s, 결승은 720px/s이며 시간이 끝나면 일반 속도 제한으로 돌아갑니다. 꼴등이 추월해서 우승할 수 있지만 우승자가 미리 지정되지는 않습니다. 이 기능은 실제 위치·속도를 바꾸는 게임 규칙입니다.
- 중단하면 이벤트도 중단됩니다. 회전/화면 크기 변경 중에는 이전 화면 좌표로 공이 튀지 않도록 이벤트를 취소하고 경기를 재개합니다.

## 회전 구조

회전판은 네 개의 뼈대와 짧게 끊긴 외곽 지지대, 작은 축으로 구성됩니다. 원판 전체를 채우지 않으며 보이는 뼈대에만 충돌합니다. 외곽의 열린 부분으로 공이 안에 들어왔다가 빠져나갈 수 있습니다. 렌더링·충돌·부스터 도착 검사에서 같은 선분 정보를 사용합니다.

## 자동 검증

- `arena-course-physics.cjs`: 실제 물리 엔진으로 기본/긴 코스의 간격, 뼈대 내부 진입, 회전 충돌, 중심점 탈출, 여러 화면·난수 조건의 골인을 검사합니다. 렌더링에 쓰지 않는 캔버스 표면만 대체합니다.
- `arena-chase.cjs`: 정지·선정·안전한 원래 가로 위치 합류·선두 격차 회복·추진력 시간 제한·장애물 충돌·옵션·일회성 처리를 검사합니다. 같은 합류 위치에서 실제 가속이 있으면 꼴등이 우승하고 없으면 기존 선두가 우승하는 비교를 포함합니다. 144개 경기 조건의 1분 이내 시간 예산과 표본에서 꼴등의 실제 우승·패배가 모두 존재하는지도 확인합니다. 표본 빈도는 모든 경기의 승률을 뜻하지 않습니다.
- `arena-browser.cjs`: PC·모바일 브라우저 조작, 옵션 저장, 중간 이벤트 정지, 결승 추격, 실제 전경 라운드의 1분 이내 완료, 뼈대 렌더링, 기존 결과·명단·팀 기능을 검사합니다.

브라우저 테스트는 임시 HTTP 서버를 시작·종료하고 외부 서비스와 운영 DB에 접근하지 않습니다. `ARENA_ARTIFACTS`를 지정하면 화면 캡처를 저장합니다. GitHub Actions의 `Arena V8 checks`가 동일한 검증을 실행합니다. 시간 검증은 테스트 표본과 정상적인 전경 실행에 대한 회귀 검증이며, 백그라운드 탭·기기 정지 같은 환경까지 보장하는 실시간 제한은 아닙니다. 실제 iPad/Safari 실기기 검증은 별도로 필요합니다.
