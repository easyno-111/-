[수학 실험실 Firebase 앱 포털 배포 방법]

1. 이 ZIP의 파일을 모두 압축 해제합니다.
2. GitHub 저장소의 기존 파일을 이 폴더의 파일로 교체하거나, 전체 파일을 업로드합니다.
3. GitHub Pages 반영 후 아래 주소로 접속합니다.
   - 홈페이지: https://easyno-111.github.io/저장소이름/
   - 관리자:   https://easyno-111.github.io/저장소이름/admin.html
4. Firebase Authentication에 만든 관리자 이메일/비밀번호로 로그인합니다.
5. 처음 한 번만 “현재 앱 한 번에 불러오기”를 누릅니다.
6. 이후에는 admin.html에서 앱 추가·수정·삭제·숨김·순서 변경을 처리합니다.

[새 HTML 앱을 추가할 때]
1. 새 HTML 파일을 GitHub 저장소에 업로드합니다. 예: newgame.html
2. admin.html → 새 앱 추가
3. 첫 번째 주소에 newgame.html 입력
4. 저장하기

[주의]
- 관리자 비밀번호는 HTML 파일에 저장되지 않습니다.
- firebaseConfig는 웹 앱 연결용 공개 설정이며, 실제 쓰기 보안은 Realtime Database 규칙의 관리자 UID가 담당합니다.
- 관리자에서 저장 권한 오류가 뜨면 Realtime Database 규칙에 입력한 UID와 로그인 계정의 UID가 같은지 확인합니다.
- 변경이 바로 보이지 않으면 브라우저에서 Ctrl+F5로 새로고침합니다.

[화면 디자인 업데이트]
- 메인 index.html은 파스텔 톤의 둥근 카드 UI로 변경되었습니다.
- 상단의 라이트/나이트 버튼으로 밝은 화면과 어두운 화면을 전환할 수 있습니다.
- 화면 모드 선택은 해당 브라우저에만 저장되며 Firebase 데이터나 관리자 화면에는 영향을 주지 않습니다.
- 관리자 화면은 기존 관리 기능과 디자인을 유지합니다.
